# Contributing

Reproducibility corrections, documentation improvements, and analysis issues are welcome through GitHub issues or pull requests.

Please do not commit API keys, credentials, patient data, or identifiable clinical material. Changes to the frozen study data, prompts, scoring instrument, or primary analysis should be clearly labelled as extensions rather than retrospective modifications of the reported study.

Before opening a pull request, run:

```bash
./run_analysis.sh
```

Report any platform or dependency differences that prevent exact reproduction.
