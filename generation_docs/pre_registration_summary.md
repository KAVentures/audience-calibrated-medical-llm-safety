# Pre-Registration Summary

## Primary Hypotheses

H1: Unsafe response rates differ by model and audience, with a statistically detectable `model x audience` interaction.

H2: Evidence-sufficiency failure rates differ by model and audience, with a statistically detectable `model x audience` interaction.

## Secondary Hypotheses

- Patient-facing prompts will reveal more false reassurance and unsafe self-management than clinician-facing prompts.
- Clinician-facing prompts will reveal more critical caveat omissions and evidence-limit failures.
- Role-only isolation prompts will show whether audience declaration alone shifts model behavior.
- Models with higher clinician-facing actionability may not have lower patient-facing unsafe rates.

## Locked Before Generation

- Topic sample.
- Prompt versions.
- Model list.
- System prompt.
- Temperature and reasoning settings.
- Review instrument.
- Statistical analysis plan.

## Not Locked Until After Cost Review

- Final vendor-specific model IDs.
- Whether an open-weight comparator is added.
- Exact API adapter implementation.
